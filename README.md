# CS180 — project webpages

Combined site for my CS180 (Intro to Computer Vision & Computational
Photography, UC Berkeley, Fall 2026) project webpages, with a project
index at the root.

- `/` — project index
- `/proj0/` — Becoming Friends with My Camera
- `/proj1/` — Images of the Russian Empire (Prokudin-Gorskii colorization)
- `/proj2/` — Fun with Filters and Frequencies

Static HTML/CSS/JS (Three.js + GSAP via CDN), no build step. `tools/`
holds the script that bakes recovered alignment offsets into proj1.

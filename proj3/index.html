The Power of Flow Models

Part A samples, guides and edits images with a pretrained text-to-image flow model. Part B builds and trains a flow-matching UNet from scratch on MNIST.

Part A · 1.1 Constructing noisy training inputs

Linear flow-matching path xt = (1−t)ε + t·x1, where t = 0 is pure noise and t = 1 is the clean image. One noise sample is reused at t = 0.25, 0.50 and 0.75.

Part A · 1.2 Classical denoising

Each noisy input is rescaled by 1/t, then Gaussian-blurred. σ is swept over 1, 2, 4, 8, 16 and the result with the lowest MSE to the clean image is shown.

Part A · 1.3 One-step denoising

One velocity prediction per input: x̂1 = xt + (1−t)·vθ(xt, t, c), with the prompt “a high quality photo”.

Part A · 1.4 Visualizing velocity

What the model adds, (1−t)·v̂t, compared with the update x1 − xt that would exactly recover the original.

Part A · 1.5 Iterative denoising with Euler sampling

xt+h = xt + h·v(xt, t), recomputing the velocity at every step. Starting from the t = 0.50 input with h = 0.02 (25 updates).

Part A · 1.6 Generating images from noise

Five independent Gaussian initial states integrated from t = 0 to 1 with 50 Euler updates, prompt “a high quality photo”.

Part A · 2.1 Classifier-free guidance

vcfg = vc + w(vc − vu) with the empty prompt as the null condition, w = 7, h = 0.02, and the same initial noises as 1.6.

Part A · 3.1 Image-to-image editing

Start from (1−tstart)ε + tstart·x1 and integrate to t = 1 with CFG (w = 7, h = 0.02, “a high quality photo”), for tstart ∈ {0.02, 0.04, 0.06, 0.10, 0.14, 0.25, 0.50}.

Part A · 3.2 Text-guided image editing

Same seven starting times, with the generic prompt replaced by an edit prompt for each image.

Part A · 3.3 Visual anagrams

Average vcfg(x, t, ca) and F(vcfg(F(x), t, cb)), where F rotates the image by 180°, inside the same Euler sampler.

Part A · 3.4 Hybrid images

Each Euler update uses lowpass(va) + vb − lowpass(vb): prompt a sets the distant structure, prompt b the close-up detail.

Part B · 1.2 Single-step denoising UNet

MNIST digits noised with z = x + σε for σ ∈ {0, 0.2, 0.4, 0.5, 0.6, 0.8, 1.0}.

Part B · 1.2.1 Training

UNet denoiser trained on σ = 0.5 with an L2 loss.

Part B · 1.2.2 Out-of-distribution testing

The σ = 0.5 denoiser applied to test digits at other noise levels.

Part B · 1.2.3 Denoising pure noise

A fresh UNet trained to map pure noise to digits.

It appears that the exact same output is being generated for all the images because if the model is taking as an input a completely random image, there is absolutely no correlation with the label. Therefore, if we desire the model to not overfit, the model must generate an "average digit" which is the collection of pixels that gives the lowest expectation of the MSE loss.

Part B · 2.1–2.3 Time-conditioned UNet (flow matching)

The UNet takes t as an extra input through fully-connected blocks and predicts the velocity x1 − x0; samples come from Euler integration from noise at t = 0 to data at t = 1.

Part B · 2.4–2.6 Class-conditioned UNet (flow matching)

Adds a one-hot class vector (dropped 10% of the time) and samples with classifier-free guidance, vu + γ(vc − vu).
